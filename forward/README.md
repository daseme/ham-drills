# Forwarding page for the old Technician address

These files are the whole content of the `daseme/ham-technicians-drills` repository, served at
https://daseme.github.io/ham-technicians-drills/. The drills moved to https://daseme.github.io/ham-drills/technician/
(source: https://github.com/daseme/ham-drills). index.html forwards there, keeping `?demo` and any `#screen`; sw.js
replaces the old offline copy on phones that installed the app here, then steps aside. Edit them in the ham-drills
repository under forward/, where they are tested, and copy them across.
