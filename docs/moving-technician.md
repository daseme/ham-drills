# Moving the Technician drills: checking an iPhone

The Technician drills moved from `daseme.github.io/ham-technicians-drills/` to `daseme.github.io/ham-drills/technician/`. The old address forwards to the new one. Progress is never deleted by the move.

## Before the move

On the phone, open the Technician drills from the home-screen icon as usual, tap **Export progress** at the bottom of the home screen, and save the file somewhere you can find it (Files, or email it to yourself). This is only a safety net: once the old address forwards, the old icon can no longer export.

## After the move

1. Open the Technician drills from the same home-screen icon as always.
2. It should land on the new address and look exactly as before: the same sections, the same number due today, the same badges.
3. If it does, you're done. Keep using that icon.

## If it shows the first-visit screen or nothing seen

The progress is still safe; this phone keeps it separately for each home-screen icon.

1. In Safari, go to `daseme.github.io/ham-drills/technician/`.
2. Tap Share, then **Add to Home Screen**.
3. Open the new icon, tap **Import progress** at the bottom of the home screen, and choose the file saved before the move.
4. Check the sections and badges look right, then remove the old icon.
